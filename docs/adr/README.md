# Decisions about the format

ADRs record non-trivial decisions about the TextCAD format (copy `0000-template.md`).

Numbers 0002, 0003, 0005, 0007–0009 and 0011–0014 were decisions about a particular implementation
(toolchain, crates, solver internals, kernel binding, tooling). They are not part of the format and
were removed when the specification was separated from implementations (2026-11-26). Where the
remaining records mention implementation details, those details are historical context, not
requirements.
