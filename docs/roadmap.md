# Roadmap

The format grows in phases (requirements section 13). Each phase extends the specification, then the
conformance corpus. Phases may overlap; a phase is complete when its gate holds. Open work is tracked as
GitHub issues in this repository, grouped under one epic per phase.

| Phase | Scope | Status |
| --- | --- | --- |
| 1 — Parts | Parameters, sketches, features, naming, metadata, STEP import | specified; open items below |
| 2 — Assemblies and BOM | `spec/assembly.md` | draft |
| 3 — PMI, GD&T, MBD | `spec/pmi.md` (to be written) | planned |
| 4 — 2D drawings | `spec/drawing.md` (to be written) | planned |
| 5 — Surfacing, sheet metal, weldments | `spec/surfaces.md`, `spec/sheet-metal.md` (to be written) | planned |
| After 5 | Native import, direct editing, a second independent implementation | evaluation |
