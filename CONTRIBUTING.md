# Contributing

- The specification, examples and corpus are licensed under Apache-2.0. Contributions are accepted
  under the same license.
- Sign off every commit (`git commit -s`) to certify the
  [Developer Certificate of Origin](https://developercertificate.org/).
- The spec in `spec/` is normative. A change to the format changes the spec chapter, the grammar if
  needed, and the conformance corpus together, and records an ADR in `docs/adr/` (copy
  `0000-template.md`) for any non-trivial decision. Decisions locked in section 2 of
  `docs/TextCAD-Requirements.md` cannot be overturned by an ADR.
- Minor versions only add (spec/versioning.md). Anything that would change the meaning of an existing
  valid file needs a major version and migration rules.
- Corpus parts are generated by the scripts in `corpus/tools/` and never edited by hand; their expected
  values are checked against the independent build123d models with
  `python3 corpus/tools/compare_reference.py corpus` (needs `pip install build123d`).
- This repository contains no implementation. Tools that implement the format are separate projects.
