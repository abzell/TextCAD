# Name

The format is called **TextCAD**. Source files use the extension `.tcad`; archived bundles use `.tcadz`.
The name is a working name and may change.

To keep a rename cheap, this file is the single place the specification states the name; the file
header keyword (`tcad`) and the extensions are the only other places the short name appears.
Implementations are encouraged to define the name and extensions in one place as well.
