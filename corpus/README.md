# Conformance corpus

Each case lives in `corpus/<name>/` as `parts/<name>.tcad` plus `expected.json`; cases with geometry
also have a `bundle.toml` and a `reference.py` build123d model that computes the same part
independently (requirements section 11). All sources are in canonical form.

A tool conforms when, for every case it supports, it reports exactly the expected diagnostics, and (if
it regenerates geometry) matches the expected values at determinism tier T2 (spec/kernel.md). The cases
do not depend on any particular tool.

## `expected.json` for sketches

| Key | Meaning |
| --- | --- |
| `note` | Why the part exists. |
| `codes` | Exact list of diagnostic codes other than information, in source order. |
| `info` | Exact list of information codes, if any are expected. |
| `dof` | Total degrees of freedom of the sketch after solving. |
| `entities` | `{ name: { "dof": n } }`: degrees of freedom per entity. |
| `points` | `{ "entity.role": [x, y] }`: solved coordinates in mm, checked to 1e-6. |
| `conflict` | Substrings that the conflict message (`E4101`) must contain. |
| `not_named` | Substrings it must *not* contain (innocent constraints). |
| `entity_count` | Number of solved entities. |

## Sketch stress parts

`sketch_fully_constrained`, `sketch_under_constrained`, `sketch_over_constrained` (must fail with
a named conflict), `sketch_tangent_chain`, `sketch_splines`, `sketch_200_entities`.

## Parts with geometry

`prim_*` (primitives), `feat_*` (detail features and patterns) and `nam_*` (naming robustness) have a
`bundle.toml`, `parts/<name>.tcad`, `expected.json` and a `reference.py` build123d model. They are
generated by `tools/gen_primitives.py`, `gen_features.py`, `gen_more_features.py`, `gen_naming_parts.py` and
`gen_hydraulic.py` (shared helpers in `corpuslib.py`; the hydraulic part sources are in `tools/hydraulic/`),
never edited by hand.

| Key | Meaning |
| --- | --- |
| `volume_mm3`, `bbox_min_mm`, `bbox_max_mm` | Closed-form values. |
| `area_mm2`, `center_of_mass_mm` | Closed-form for the primitives; for parts with fillets and tapers taken from the build123d model (listed under `baseline`). |
| `topology` | Counts that must match exactly (any of `solids`, `faces`, `edges`, `vertices`). |
| `sweeps` | `[{ "set": { "param": "value" }, "volume_mm3", "bbox_min_mm", "bbox_max_mm" }]`: for every parameter set the part must build, keep the same persistent names, and match. |

## Connectors (draft)

`con_*` cases cover `connector` (spec/assembly.md § `connector`, still a draft; issue #28). They are
format 0.2 parts generated by `tools/gen_connectors.py`, never edited by hand. Three have geometry and
use the keys above plus:

| Key | Meaning |
| --- | --- |
| `connectors` | `{ name: { "origin_mm": [x, y, z], "x": [...], "y": [...], "z": [...] } }`: every connector of the part, including the implicit `origin`, in the part frame. Origins are checked at T2 (1e-5 mm), axis components to 1e-9. |
| `absent` | Connector names that must **not** exist (for example a skipped pattern instance, or the bare name of a hole with several positions). |
| `sweeps[].connectors` | The expected frames for that parameter set. |

The expected frames are computed in closed form by the generator and cross-checked against frames
that the build123d model derives from its own geometry (face centroids and normals, circle centres,
cylinder axes). The `con_err_*` cases are invalid parts that must fail with exactly the listed
code (`codes`, `fails`), as the sketch stress parts do.

`python3 corpus/tools/compare_reference.py corpus` cross-checks every `expected.json` against its
build123d model at T2 (needs `pip install build123d`).

## The 54 cases

| Group | Parts |
| --- | --- |
| Sketch stress (6) | `sketch_*` |
| Primitives (8) | `prim_*`, closed-form |
| Features (17) | `feat_*`: every extrude end condition (`feat_extrude_ends`), holes of all four types, constant and variable fillet, chamfer, shell, draft, rib, ruled and guided loft, sweep, booleans, patterns with skips, pattern of pattern, mirror |
| Naming robustness (6) | `nam_*` with sweeps of 9 to 81 parameter sets each |
| Connectors (11, draft) | `con_hole_frames` (with a thickness sweep), `con_explicit`, `con_revolution`; `con_err_*`: E5001 (missing z; csys with origin), E5002, E6011 (x parallel to z; zero direction), E3001, E2101, E0103 |
| Hydraulic (6) | `hyd_rod_clevis`, `hyd_rod_eye`, `hyd_end_cap`, `hyd_tie_rod_head`, `hyd_manifold_4port`, `hyd_grease_pin`; expected values from the independent build123d model (`baseline` lists every value taken from it) |

Surface area, center of mass and volume in `expected.json` are integrated to a relative precision of
1e-12.
